# 台北至東京機票價格爬蟲與分析

## 專案簡介

本專案為團隊合作開發，針對 Trip.com 上台北（TPE／TSA）至東京（NRT／HND）航線的機票報價，從資料蒐集、清洗、統計到視覺化完整實作。

團隊共取得 2,873 筆航班報價，篩選出 **1,511 筆直飛經濟艙**資料，出發日期涵蓋 2026 年 4～12 月，其中 4 月資料最完整（1,022 筆），因此分析聚焦於 4 月出發航班在不同出發日期、星期別及清明連假期間的票價變化。

## 專案動機

日本是台灣旅客熱門的出國目的地，兩地往來頻繁。團隊希望以爬蟲持續追蹤台北至東京的票價，觀察票價隨出發日期變化的規律，作為購票時機的參考。

## 團隊工作

* **資料蒐集**：使用 Playwright 搭配 playwright-stealth 模擬一般瀏覽器操作，依出發日期批次產生搜尋網址，以 asyncio 並行爬取；透過滾動載入完整航班列表，擷取航空公司、航班類型、飛行時間、起降時間與機場、票價、行李與設施等欄位，並以 Pandas 去除重複資料。
* **資料清洗與基礎統計**：轉換日期與票價欄位格式，檢視各欄位分布與航空公司、航班類型、艙等的類別，篩選出直飛經濟艙資料，並找出票價最高與最低的航班。
* **資料視覺化**：以熱圖呈現各月份航空公司的資料分布，並以折線圖、箱形圖與長條圖，觀察各航空公司的票價差異及月份趨勢。

## 個人貢獻

負責票價統計分析與資料視覺化（簡報第 24～28 頁）。

* **資料整理**：使用 Pandas 將日期欄位轉為 datetime，篩選 4 月資料（1,022 筆），依出發日期與星期別分組，計算每日最低與平均票價。
* **資料視覺化**：使用 Matplotlib 繪製每日票價趨勢折線圖與星期別平均票價長條圖，並以背景色標示週末與清明連假（4/3～4/6）。

## 個人分析結果

* **清明連假衝擊最大**：4/3（連假首日）為 4 月平均票價最高的一天，約 22,480 元。
* **星期別差異**：週二平均最低（14,562 元），週六最高（16,845 元），週五至週日平均均在 1.6 萬元以上。
* **月中平日較平穩**：4/7～4/24 平日平均票價約 14,500～15,200 元；4/25 之後每日僅 3～6 筆資料，平均價（5,066～10,540 元）受樣本過少影響，不列入比較。

清明連假期間票價明顯上漲，連假首日平均票價最高。

週二平均票價較低，週六平均票價較高，呈現星期別票價差異。

月中平日票價相對穩定，月底因航班樣本數較少，分析結果較容易受到資料量影響。
