# 台北至東京機票價格爬蟲與購票時機分析

本專案為三人團隊合作开发，針對台北至東京（TPE - NRT/HND）航線進行機票資料蒐集與價格趨勢分析。透過大數據分析，找出相對低價的購票時機與連假期間的票價變化規律，共取得約 2,873 筆航班報價資料。

## 👥 團隊分工與個人貢獻
在團隊中我主要負責**資料清洗、統計分析與資料視覺化**：
* **資料清洗與整理**：使用 `Pandas` 進行日期與票價欄位處理，精準篩選出「直飛經濟艙」之有效資料。
* **統計指標計算**：依據不同「日期」與「星期別」歸納並計算航班的最低價與平均票價。
* **資料視覺化**：使用 `Matplotlib` 繪製票價趨勢走勢圖、星期別平均票價對比圖，直觀呈現連假效應。

## 📊 專案成果與分析亮點
* **數據規模**：成功處理並分析 2,873 筆航班報價。
* **決策支持**：透過圖表成功定位出特定星期與淡旺季的價格甜蜜點，提供明確的購票時機建議。

## 🛠️ 使用技術
* **資料處理**：Python, Pandas
* **資料視覺化**：Matplotlib
