## 台北至東京機票價格爬蟲與購票時機分析

本專案為三人團隊合作開發，針對台北至東京（TPE - NRT/HND）航線進行機票資料蒐集與價格趨勢分析，共取得 2,873 筆航班報價資料。

## 👥 團隊分工與個人貢獻
* 資料清洗與整理：使用 Pandas 針對已篩選之直飛經濟艙資料，進行日期與票價欄位的格式轉換、異常值清洗與結構化整理。
* 票價統計分析：依據不同「日期」與「星期別」進行分組歸納，計算並統計航班的最低與平均票價。
* 資料視覺化：使用 Matplotlib 繪製票價趨勢走勢圖、星期別平均票價對比圖，清楚呈現連假期間的票價波動趨勢。

## 📊 專案成果與分析亮點
* 數據規模：團隊共取得 2,873 筆航班報價，篩選出 1,511 筆直飛經濟艙有效資料進行清洗與分析。
* 分析成果：透過圖表歸納出特定星期的票價變化規律，提供具體的購票時機參考。

## 🛠️ 使用技術
* 資料處理：Python, Pandas
* 資料視覺化：Matplotlib
